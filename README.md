# 👗 Fashion Store 2026 - E-Commerce Boutique

A modern and elegant e-commerce website for fashion boutique, built with PHP & MySQL.

### ✨ Features
- Product catalog with categories
- Shopping cart (Panier)
- User authentication
- Admin panel
- Contact page
- Responsive design

### 🛠️ Tech Stack
- PHP
- MySQL (database.sql)
- HTML / CSS / JavaScript
- XAMPP

### 🚀 How to run locally
1. Clone the repo
2. Put it in `htdocs`
3. Import `database.sql` in phpMyAdmin
4. Start Apache & MySQL
